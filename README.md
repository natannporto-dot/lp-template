# LP Template — Landing Page

Template de Landing Page moderno e responsivo desenvolvido para projetos de apresentação, aquisição e conversão de negócios.

O projeto foi desenvolvido com foco em uma estrutura simples, reutilizável e fácil de personalizar para diferentes clientes e segmentos.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Vercel

## ✨ Funcionalidades

- Landing Page responsiva
- Layout adaptado para desktop e mobile
- Animações de entrada com Intersection Observer
- Interação visual da imagem principal
- Configuração dinâmica através do `config.js`
- Alteração de textos e informações sem modificar o HTML principal
- Configuração dinâmica de cores
- Formulário de diagnóstico
- Integração com API para envio do formulário
- SEO básico com título e meta description
- Favicon personalizado
- Estrutura preparada para reutilização em novos projetos

## 📱 Responsividade

O layout foi desenvolvido para funcionar em diferentes tamanhos de tela:

- Desktop
- Notebook
- Tablet
- Smartphone
